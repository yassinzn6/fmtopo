# AMEGDT GeoAI (V101)

منصة نظم المعلومات الجغرافية والاستشعار عن بعد والذكاء الاصطناعي الجغرافي (الأكاديمية المغربية للدراسات الجغرافية والتنمية الترابية - AMEGDT).

## المزايا والخصائص الرئيسية

- واجهة مستخدم حديثة ومتجاوبة (Plus UI Glassmorphism).
- منصة مفتوحة ومجانية 100% تعمل على المتصفح (Client-side / Local-first) دون الحاجة إلى خادم أو قاعدة بيانات خاصة.
- دعم كامل لأنظمة الإحداثيات المغربية (Lambert Merchich Zones I, II, III, IV) و UTM و WGS84.
- أدوات التحليل المكاني المتقدمة: Zonal Statistics, Buffer, Intersect, Union, Difference.
- دعم ملفات الراستر GeoTIFF السحابية والمحلية، وحساب درجات الانحدار (Slope) والظلال (Hillshade).
- رسم المقاطع الطبوغرافية وحساب الارتفاعات الفورية (Elevation Profile).
- التصدير والاستيراد الشامل: DXF (AutoCAD), Excel (.xlsx), KML, KMZ, GeoJSON, GPX, وحزم المشاريع (.fmtopo).
- دعم تثبيت التطبيق كـ PWA على الهواتف والحواسيب بشعار واسم AMEGDT GeoAI.

## ملفات التطبيق والشعار

- `index.html` (الملف الرئيسي للتطبيق)
- `manifest.webmanifest` (بيانات تثبيت التطبيق PWA)
- `amegdt-geoai-logo.png` (الشعار الرسمي عالي الدقة)
- `amegdt-geoai-192.png` (أيقونة التطبيق 192x192)
- `amegdt-geoai-512.png` (أيقونة التطبيق 512x512)
